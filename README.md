# Rex's Rooter Plumbing website

Static site (plain HTML, CSS and JS, no build step). Open `index.html` or deploy the folder as-is.

- `index.html`: home (hero, problem picker, services, gallery, service-area checker, reviews, FAQ)
- `services.html`: service detail page
- `css/styles.css`, `js/main.js`: all styles and widgets
- `images/`: optimized WebP photos taken from the current rexrooterplumbing.com site

## Notes
- All calls to action are click-to-call only (no texting, no forms). No email or office hours by client request.

- Real customer reviews (none found; the carousel shows "reasons to choose us" instead)
